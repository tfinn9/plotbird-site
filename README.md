# Plotbird

Website for **Plotbird**, a Christchurch-based aerial mapping and property imagery service.

- Website: https://plotbird.co.nz
- Contact: plotbirdnz@gmail.com
- Hosting target: Cloudflare Pages
- Stack: static HTML, CSS and vanilla JavaScript

Mapping examples are sourced from Tom Finn's public drone mapping portfolio at https://github.com/tfinn9/tom-finn-drone-mapping-portfolio.
