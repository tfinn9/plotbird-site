# Plotbird

Website for **Plotbird**, a Christchurch-based aerial mapping and property imagery service.

## Domain

https://plotbird.co.nz

## Contact

plotbirdnz@gmail.com

## Stack

Static HTML, CSS and vanilla JavaScript. No build step required.

## Hosting

Designed for static deployment from the `main` branch.

## Portfolio imagery

Current mapping examples are sourced from Tom Finn’s public drone mapping portfolio repository:
https://github.com/tfinn9/tom-finn-drone-mapping-portfolio

The examples include Scruttons Road farm mapping, an estuary shoreline orthomosaic and Jellicoe Street urban mapping.
